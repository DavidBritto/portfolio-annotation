03. Production Case Study: Zero to Cloud

[ Architecture Deep-Dive ]

Deconstructing Legacy SaaS into AWS Serverless Economics

Migrated the complete ecommerce infrastructure of Onaxale away from recurring Tiendanube monthly fees into a decoupled, pay-per-request architecture on Amazon Web Services.

Step 01 · Global Edge
S3 & CloudFront CDN
Static asset delivery hosted on Amazon S3 and distributed via CloudFront edge locations with TLS 1.3 encryption. Sub-50ms latency worldwide with zero servers to patch.
Step 02 · Compute & APIs
API Gateway & Lambda
Python microservices orchestrate cart lifecycles, webhook verifications, and Mercado Pago Checkout integration. Zero idle computing costs—charges trigger strictly on demand.
Step 03 · State & Logs
DynamoDB & CloudWatch
NoSQL order tracking and customer persistence in Amazon DynamoDB. Centralized telemetry, CloudWatch alarms, and automated point-in-time recovery.
