# SDD change artifacts

This directory holds **formal planning contracts** for medium/large work on this repo.

## Created by

- **`sdd-new`** — creates `proposal.md` and `spec.md`, then waits for explicit approval before implementation.
- **Phase agents** — `sdd-propose`, `sdd-spec`, `sdd-design`, `sdd-tasks`, etc. may mirror content here when using hybrid persistence.

## Not used for

- Typo fixes, single CSS tweaks, or link updates in `index.html` — edit directly without SDD.

## Active changes

_None yet._ After `sdd-explore` or `sdd-new`, add a subfolder or top-level `proposal.md` / `spec.md` for the change name you choose.
